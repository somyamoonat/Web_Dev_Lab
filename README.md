## Overview

This repository contains my lab work and practical assignments for the **Programming for Web Development – I Laboratory** course. It covers the basics of the command line, Git and GitHub, semantic HTML5, CSS styling, Flexbox, and CSS Grid.

---

## Practicals List

### Module 1: Terminal & Git Foundations (P1–P4)

- **[P1: Project folder and terminal navigation](P1/Readme.md)**  
  Creating project folders and practicing common terminal commands like `pwd`, `mkdir`, and `cd` to move around directories.

- **[P2: Portfolio repo with an initial commit](P2/Readme.md)**  
  Setting up a new Git repository, adding a `.gitignore` file, and making the first commit to GitHub.

- **[P3: Feature-branch Git workflow](P3/Readme.md)**  
  Creating a separate feature branch to make changes safely, pushing it, and merging it back into `main`.

- **[P4: GitHub README and version tags](P4/Readme.md)**  
  Writing project documentation in Markdown and creating release version tags like `v1.0.0`.

---

### Module 2: HTML & CSS Foundations (P5–P9)

- **[P5: Semantic bio page](P5/index.html)**  
  Building an "About Me" page using proper HTML5 semantic tags like `header`, `section`, `article`, and `footer`.

- **[P6: Full portfolio page structure in semantic HTML](P6/index.html)**  
  Creating a complete portfolio page structure with about, skills, projects, and a contact form.

- **[P7: Design tokens and typography system in CSS](P7/index.html)**  
  Using CSS variables for colors, fonts, and spacing to keep the website styling consistent.

- **[P8: Sticky navbar and card overlay using CSS positioning](P8/index.html)**  
  Making a navbar stick to the top of the screen while scrolling, and creating cards with hover overlays using CSS positioning.

- **[P9: Responsive navbar and card grid using Flexbox](P9/index.html)**  
  Using Flexbox to build a navigation bar and cards that automatically wrap and adjust on smaller screens.

---

### Module 3: CSS Layout Systems (P10–P13)

- **[P10: Portfolio header and footer with advanced Flexbox](P10/index.html)**  
  Building a clean portfolio header and a multi-column footer using Flexbox alignment.

- **[P11: Newspaper-style three-column layout with CSS Grid](P11/index.html)**  
  Creating a classic 3-column newspaper article layout using CSS Grid.

- **[P12: Portfolio projects grid with advanced CSS Grid](P12/index.html)**  
  Building a project showcase grid where different cards span across multiple columns and rows.

- **[P13: Choosing between Flexbox and Grid for a shared layout](P13/index.html)**  
  Comparing Flexbox and CSS Grid side by side to understand when to use each layout method.
